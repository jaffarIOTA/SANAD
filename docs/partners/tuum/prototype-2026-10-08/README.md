# Tuum prototype — SME direct lending for a UAE development fund

The core banking partner's prototype screens, shared on 2026-10-08 and supplied again on
2026-10-09. They are the source of the request that `products/sme-term-conventional`, the UAE
fund's configuration (`config/tenants/sme-fund-ae/`) and the business pipeline (`/business`
in ops) were built against. The traceability matrix is `../SME-TRACEABILITY.md`.

**Redacted.** The repository is public. Before committing, personal data was blacked out on
every screen: the applicant's personal name, email address, Emirates ID, trade licence
number, credit-bureau report number, and the name of the fund's staff member. Redaction was
located by OCR and verified by a second OCR pass and by eye. The figures, rules, labels and
workflow the request depends on are unchanged.
